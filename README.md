# 🤖 FinBot - Finansal Takip ve Analiz Botu

FinBot, kişisel finans verilerini takip etmek, analiz etmek ve yönetmek için geliştirilmiş Python tabanlı bir otomasyon projesidir. Bu proje, güçlü bir Python arka ucu (Backend) ile kullanıcı dostu bir web arayüzünü (Frontend) birleştirir.

## ✨ Özellikler
* **Veri Yönetimi:** Python ve SQL tabanlı veritabanı mimarisi ile güvenli veri saklama.
* **Otomasyon:** `main.py` üzerinden çalışan bot mekanizması.
* **Web Arayüzü:** `finbot-frontend` klasörü altında modern ve responsive kullanıcı arayüzü.
* **Veritabanı Entegrasyonu:** `database.py` ile ORM (Nesne İlişkisel Eşleştirme) yapısı.

## 📂 Proje Yapısı
* `main.py` - Uygulamanın ana giriş noktası ve bot mantığı.
* `database.py` - Veritabanı bağlantıları ve tablo modelleri.
* `finbot-frontend/` - HTML, CSS ve JavaScript dosyalarını içeren ön yüz klasörü.
* `nasil calisir.txt` - Projenin çalışma mantığını anlatan dokümantasyon.

## 🛠️ Kullanılan Teknolojiler
* **Dil:** Python 3.x
* **Veritabanı:** SQL (SQLAlchemy/SQLite)
* **Frontend:** HTML5, CSS3
* **Versiyon Kontrol:** Git & GitHub
